# STVNLive.apk

Public APK distribution repository for STVN Live.

This repository hosts installable STVN Live Android APK releases. The source
code lives in the private `jp2creation/STVNLive` repository.

## Download

Use the latest GitHub release and download `STVNLive.apk`.

## Update Channel

The STVN Live app checks this repository for:

- `STVNLive.apk` for stable releases
- `STVNLive-beta.apk` for pre-release builds
- `STVNLive-<version>.apk` for versioned release archives
